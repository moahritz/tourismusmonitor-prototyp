# Tourismusmonitor Vorarlberg – Prototyp

Interaktiver Prototyp einer monatlichen Schätzung der touristischen Bruttowertschöpfung aus Verwaltungsdaten (UVA, Lohndaten, Beherbergungsstatistik), kalibriert am regionalen Tourismus-Satellitenkonto.

**Alle Zahlen und Destinationen sind fiktiv.** Keine amtliche Statistik und keine Veröffentlichung des Landes Vorarlberg oder von Vorarlberg Tourismus.

Die Seite ist eine einzelne, eigenständige `index.html` (Daten, d3 und Schrift eingebettet, keine externen Anfragen).
